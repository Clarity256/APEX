\section{实验设计}

实验应围绕同一批低轨卫星场景实例比较不同方法。建议基线包括最近可见卫星归属、
最佳信道归属、软切换惩罚归属、全时域混合整数规划和滚动窗口归属。评价指标包括：

\begin{itemize}
\item 平均需求满足率；
\item 最差或第五百分位小区满足率；
\item 对数公平效用；
\item 总服务量；
\item 总切换次数；
\item 逐小区切换预算违反次数；
\item 求解时间。
\end{itemize}

主结论应限定在无可避免切换预算违反的场景中。若存在因可见性断裂导致的强制切换，
需要将其作为 emergency handover 单独统计，而不应混入硬预算满足性的主结论。
