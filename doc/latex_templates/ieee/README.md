# IEEE Conference Templates

This directory stores the upstream IEEE conference template ZIP archives.

Active paper source lives in `../../wcnc2027/`. The working English draft keeps
local copies of `IEEEtran.cls` and `IEEEtran.bst` next to `main.tex`, so normal
compilation does not depend on this archival directory.

Current archives:

- `archives/conference-latex-template.zip`
- `archives/IEEEtranBST2.zip`

Keep these archives unchanged unless the official WCNC 2027 author kit provides
a newer template.
